<h1>Hi, I'm Mike</h1>

**Network and systems administrator.** I design, build and run a two-node Proxmox cluster and about 50 self-hosted services, and I automate the boring parts.

### 🖧 What I run

- **Virtualization:** Proxmox VE cluster (VMs and LXC containers), Unraid NAS for storage and backups
- **Networking:** managed PoE switching, TP-Link Omada Wi-Fi, VLAN segmentation, Pi-hole DNS, WireGuard and Tailscale for remote access, Cloudflare Tunnels and a Caddy reverse proxy for anything exposed
- **Monitoring:** Prometheus, Grafana, Uptime Kuma, centralized rsyslog, change-only alerting
- **Automation:** OpenTofu/Terraform, Ansible, cloud-init, n8n, PowerShell, Bash, Python
- **Services:** PostgreSQL, Docker, Nextcloud, Vaultwarden, Home Assistant
